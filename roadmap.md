## Concluído
- [x] Botões de navegação "Voltar" e "Menu inicial" no topo de todas as telas (Voltar volta uma etapa; desabilitado quando não há para onde voltar)
- [x] Checagem geral do app: login, painel de clientes, clima interno, administração e regras de acesso verificados com conta real logada
- [x] Importação de CSV aceita nomes de coluna com maiúsculas/minúsculas, acentos, espaços, símbolos e números (ex.: "E-mail do Cliente", "Nota (1 a 10)", "Data de envio"), com prévia mostrando qual coluna foi reconhecida; datas em formato brasileiro (15/03/2026) e notas como "9,0" ou "Nota 9" são convertidas corretamente
- [x] Painel de feedbacks de clientes (NPS, distribuição de notas, pizza por categoria, nuvem de palavras, filtros, exportação CSV/PNG/PDF)
- [x] Painel de clima interno (score geral, dimensões, tendência mensal, visão por setor, lista de respostas)
- [x] Área de administração (perfis de acesso, importação de CSV, histórico de importações)
- [x] Login com e-mail/senha e Google, controle de acesso por perfil (Admin, Gestor, Colaborador)
